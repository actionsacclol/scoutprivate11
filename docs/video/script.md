# Krypt Scout — YouTube Launch Video Script

**Target length:** 10:30 (acceptable range 8–12 min)
**Voice:** blunt, fast, zero hype-guru energy. No "guys, smash that like button" until the very end, and even then, once, dry.
**On-screen text:** monospace, all-caps where the app itself uses all-caps. No emojis anywhere on screen.
**Recording note:** capture everything at 1440p+ with the app in dark fullscreen. The app IS the aesthetic — never overlay stock footage.

All app labels in this script are verbatim from the UI (sidebar: DASHBOARD, TODAY, BOARDS, TERMINAL, PICKS, PARLAY, TRACKER, BONUSES, DISCORD, VALUE, PERFORMANCE, MODELS, INTEL, SETTINGS, ABOUT).

## APPENDIX A — B-ROLL SHOT LIST

Capture everything BEFORE writing final VO timings. Record long takes; cut later. App in PRO mode for terminal shots, SIMPLE for the daily-flow shots unless noted. Demo mode is acceptable for motion-heavy shots (terminal runs fully in demo) but use a real slate day for PICKS/TRACKER so numbers are genuine.

1. **TERMINAL — hero take (3+ min continuous).** Full screen. ASCII banner, slate field nodes drifting, wire log, model-vs-market chart, MODEL RACK, ping. Get: slow push-in, slow pan L→R, and a locked wide. This take feeds the cold open, 5:30 segment, end card, and Short A.
2. **TERMINAL — banner type-on.** Navigate away and back to catch the banner/wire repopulating fresh.
3. **PERFORMANCE — record with losses.** 30-day daily accuracy chart including sub-50% red days, stat tiles, CLV tile + hover its tooltip.
4. **PICKS — one STRONG card, SIMPLE mode.** Slow zooms: TAKE eyebrow, tier badge (+ hover tooltips on STRONG, LEAN, MODEL across cards), price + book badge, plain-English sentence.
5. **PICKS — line shop.** Book chips with prices, BEST badge, pin icons on preferred books. Hover a few chips.
6. **PICKS — BET NOW click** → book site opens (be ready to cut fast; don't show logged-in book account state).
7. **PICKS — TRACK BET click** → flips to TRACKED. Clean take, cursor deliberate.
8. **TRACKER — pending bet row appearing**, then a settled day: table with W/L, equity curve with a drawdown, stat tiles.
9. **PICKS PRO mode** — same card after mode flip: prob bars, +EV%, 1/4 KELLY line.
10. **PARLAY — build a 3-leg slip.** Left panel leg picking, slip filling, verdict stats (BOOKS PAY / WIN CHANCE / FAIR PAYOUT), the red honesty line, the compounding-vig footer note. Also capture: removing a leg (drag shrinks) and the blocked same-game leg interaction.
11. **DASHBOARD** — hero strip pan, top pick spotlight, quick actions.
12. **Onboarding — full 3-step run.** Book tiles selecting (watch the 1/2/3/4 order numbers), SIMPLE/PRO cards, flow rows, ENTER THE TERMINAL click. Re-arm via ABOUT → "Replay onboarding".
13. **Install sequence:** GitHub Releases page, download, SmartScreen box ("More info" → "Run anyway"), installer, first launch with backend status dot amber→green. Capture on a clean Windows VM if possible.
14. **GitHub repo source scroll** — README, `src/`, `backend/kryptscout/` tree.
15. **SETTINGS** — scheduler intervals + next-run countdowns; the free-odds description text ("ESPN lines plus Polymarket and Kalshi… no key needed"); backend supervisor log.
16. **MODELS** — nine engine cards; FETCH LATEST with the CRT console streaming; hover live-vs-backtest records.
17. **ABOUT** — models table slow scroll (all nine rows), the honest note under the table, "Free & open source · no ads, no telemetry · MIT license" line, krypt.cc / Discord buttons.
18. **DISCORD setup end-to-end** — webhook creation in Discord, paste (masked), tier toggles, schedule, test send, the card landing in a channel.
19. **BONUSES page** — featured book card, claim buttons (for the disclosure segment).
20. **INTEL page** — injuries table + weather cards (nice cutaway filler; not scripted, keep 20s).
21. **Cursorless locked wides** of TERMINAL and DASHBOARD for background/title-card use.

Hygiene: hide personal webhook URLs (the app masks them — verify before publishing), use a test Discord server, clear any real bankroll numbers you don't want public.
